
# Experiment 8 - Book Management System

## Aim
To build a simple RESTful API using Node.js and Express.js for managing a book collection with CRUD operations.

## Resources Utilized
1. Visual Studio Code
2. Node.js
3. Express.js
4. JavaScript
5. HTML5
6. CSS3
7. Google Chrome
8. npm (Node Package Manager)

## Features
1. Add new books.
2. View all books.
3. Update book details.
4. Delete books.
5. Manage book collection using RESTful API.

## How to Run
1. Open the project in Visual Studio Code.
2. Open the terminal.
3. Install the required packages using npm.
4. Start the Node.js server.
5. Open index.html in the browser.
6. Add, view, update and delete books.

## Conclusion
Successfully developed a Book Management System using Node.js and Express.js with CRUD operations.
